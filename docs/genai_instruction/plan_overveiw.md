# 開発計画（Vercel + Vue.js・リスク先行型）

このドキュメントは、「不動産価値情報収集ツール」のコア機能開発におけるステップバイステップの計画を示します。

## フェーズ 1: 基盤構築と最重要リスク検証 (期間目安: X日〜Y週間)

### ステップ1: 【セットアップ】Vue.js + Vercel プロジェクト初期化
* **指示:** `npm create vue@latest` を実行し、プロジェクトを初期化してください。TypeScript、PWA、テストフレームワークなどのオプションを選択してください。Vercelアカウントを設定し、GitHubリポジトリと連携させてください。
* **成果物:** Vue.jsプロジェクト構造、Vercelデプロイ環境。

### ステップ2: 【インフラ】データベース構築
* **指示:** Vercelと相性の良いデータベース（例: PlanetScale、Supabase、Neon等）を選択し、データベースクラスターを作成してください。Vercel Functionsからアクセス可能な設定を行い、DB接続情報を環境変数として安全に保存してください。
* **成果物:** 稼働中のデータベースクラスター、DB接続情報。

### ステップ3: 【バックエンド】Vercel Functions-DB接続検証
* **指示:** Vercel Functions（Node.js/TypeScript）で簡単なAPI関数を作成し、ステップ2で作成したDBに接続できることを確認してください。基本的なクエリ (`SELECT 1;`など) を実行してください。環境変数からDB接続情報を取得するよう実装してください。
* **成果物:** DB接続確認済みのVercel Functions。

### ステップ4: 【調査】賃料情報収集 - 利用規約確認
* **指示:** 賃料情報収集の対象候補となる不動産ポータルサイト（例: SUUMO, HOME'S）の利用規約を調査し、スクレイピング（自動情報収集）が許可されているか、禁止されているか、あるいはグレーゾーンかを確認し、結果を報告してください。**この結果に基づき、次のステップの方針を決定します。**
* **成果物:** 利用規約調査結果レポート。

### ステップ5: 【バックエンド/PoC】賃料情報収集 - 技術検証
* **指示:** ステップ4の結果に基づき、以下のいずれかのVercel Functions (`executeRentalScraping`相当) を作成し、技術検証を行ってください。
    * **(規約OKの場合):** Node.jsで対象サイトから賃貸情報（賃料、管理費、間取り等）をスクレイピングし、データを整形してDBに保存する処理を実装・検証してください。Vercel Functionsの実行時間制限等も考慮してください。
    * **(規約NGの場合):** 国土交通省不動産取引価格情報等の代替データソースから賃貸関連情報を取得し、整形してDBに保存する処理を実装・検証してください。
* **成果物:** 賃料情報収集・DB保存Vercel Functionsプロトタイプ、DBテーブルスキーマ案。

## フェーズ 2: コアAPIと認証の実装 (期間目安: Y日〜Z週間)

### ステップ6: 【バックエンド】Vercel Functions API基盤設定
* **指示:** Vercel Functionsを使用してREST APIエンドポイントを作成し、基本的な設定を行ってください。`/api`ディレクトリ構造を設定してください。
* **成果物:** Vercel Functions APIエンドポイント。

### ステップ7: 【バックエンド】ジオコーディングAPI実装
* **指示:** 住所を緯度経度に変換するVercel Functions (`/api/geocode`) をNode.js/TypeScriptで作成し、Google Geocoding APIを呼び出すように実装してください（APIキーは環境変数管理）。
* **成果物:** ジオコーディングAPI。

### ステップ8: 【バックエンド】施設検索API実装
* **指示:** 緯度経度から周辺施設（徒歩10分圏内）を検索するVercel Functions (`/api/facilities`) をNode.js/TypeScriptで作成し、Google Places APIおよびDistance Matrix APIを呼び出すように実装してください。
* **成果物:** 施設検索API。

### ステップ9: 【インフラ/バックエンド】認証機能実装
* **指示:** 適切な認証サービス（例: Auth0、Supabase Auth、Firebase Auth等）を選択・設定してください。作成したVercel Functions APIエンドポイントに認証を必須とする設定を適用してください。
* **成果物:** 認証サービス、認証が適用されたAPI。

## フェーズ 3: 非同期処理とフロントエンド連携 (期間目安: Z日〜W週間)

### ステップ10: 【インフラ/バックエンド】非同期処理基盤設定
* **指示:** 賃料情報収集処理用の非同期処理基盤を構築してください（例: Vercel Functions + Queue service、またはWebhook方式）。ステップ5で作成した賃料収集関数を非同期実行できるよう設定してください。
* **成果物:** 非同期処理基盤、トリガー設定。

### ステップ11: 【バックエンド】賃料検索開始API実装
* **指示:** 賃料検索を開始するためのVercel Functions (`/api/rentals/start-search`) をNode.js/TypeScriptで作成してください。リクエストから検索条件を受け取り、非同期処理を開始し、即時レスポンスを返すように実装してください。認証を必須にしてください。
* **成果物:** 賃料検索開始API。

### ステップ12: 【バックエンド】結果取得API実装
* **指示:** 賃料検索の結果をDBから取得するためのVercel Functions (`/api/rentals/get-result`) を作成してください（ポーリング用）。リクエスト（検索ID等）に基づきDBを検索し、結果または処理中ステータスを返すように実装してください。認証を必須にしてください。
* **成果物:** 結果取得API。

### ステップ13: 【フロントエンド】Vercel Hosting設定と基本UI
* **指示:** Vue.jsで基本的なUI（ログイン/サインアップ画面、メイン画面のレイアウト）を作成し、Vercelにデプロイしてください。Vue Router、状態管理（Pinia推奨）を設定してください。
* **成果物:** デプロイされた基本的なVue.jsフロントエンドUI。

### ステップ14: 【フロントエンド】フロントエンド機能実装
* **指示:** Vue.js ecosystem（Vue 3 Composition API、Pinia等）を用いて認証フロー、バックエンドAPI呼び出し（同期・非同期開始・結果取得ポーリング）、地図ライブラリ連携（マーカー・アイコン表示）、情報エリア表示（㎡単価、賃料リスト、処理中表示、結果更新）を実装してください。
* **成果物:** 全てのコア機能を実装したVue.jsフロントエンドアプリケーション。

## フェーズ 4: 統合テストとデプロイ (期間目安: W日〜V週間)

### ステップ15: 【テスト】統合テスト
* **指示:** 全ての機能を結合し、ユーザーシナリオに沿ったテストを実施してください。認証、API連携、非同期処理、DB連携、表示更新、エラーハンドリングなどを確認してください。
* **成果物:** テスト結果レポート、バグリスト。

### ステップ16: 【デプロイ】本番環境準備 (オプション)
* **指示:** 必要に応じて、本番環境用のVercel環境（Production Branch）を構築・設定してください。環境変数や独自ドメインの設定を行ってください。
* **成果物:** 本番環境。

### ステップ17: 【調整】最終調整とリリース
* **指示:** テストで見つかったバグを修正し、最終調整を行ってください。準備が整い次第、Vercel本番環境にリリースしてください。
* **成果物:** リリースされたアプリケーション。
